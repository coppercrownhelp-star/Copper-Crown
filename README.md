# Copper & Crown Website

Frontend starter for Copper & Crown.

## Files
- `index.html` — main website
- `admin.html` — demo admin portal
- `css/style.css` — styling
- `js/app.js` — forms, local demo storage, tracking and admin rendering

## Important
This version is a front-end prototype. Customer requests are stored only in the browser's localStorage. Before using this publicly for real customer data, add a secure backend/database, authenticated admin access, server-side validation, and a real payment provider.
